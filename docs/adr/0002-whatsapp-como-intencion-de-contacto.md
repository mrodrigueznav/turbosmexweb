# WhatsApp se mide como intención de contacto

Sin WhatsApp Business API ni CRM, el sitio registrará clics hacia WhatsApp y los enriquecerá con página, campaña, dispositivo y sesión. Estos datos se reportarán como intención estimada de contacto, no como conversaciones confirmadas, porque el sitio no puede saber si el usuario envió o atendió el mensaje dentro de WhatsApp.
