# Astro con endpoints PHP y SQLite local

Para la fase 1 se eligió Astro como sitio estático, endpoints PHP para formularios y SQLite fuera del directorio público para conservar leads, sin WordPress, CMS, CRM ni base de datos remota. Esta combinación reduce dependencias y mantenimiento, permite publicar en el servidor PHP existente y deja la interfaz editorial como una decisión posterior basada en datos reales.

## Consecuencias

- Los leads requieren respaldos del servidor y un mecanismo protegido de exportación.
- No habrá panel de administración en la fase 1.
- El almacenamiento indefinido debe revisarse junto con el aviso de privacidad.
