## Criterio editorial

1. Exportar para cada URL las impresiones, clics, CTR, posición, sesiones,
   páginas de entrada y conversiones verificables de los últimos 3 meses.
2. Registrar enlaces entrantes conocidos y comprobar que la URL todavía
   representa una necesidad real del negocio.
3. Conservar y actualizar únicamente si hay evidencia o una utilidad clara para
   una persona que busca el servicio. No se infieren ventas ni conversaciones a
   partir de clics.
4. Si se conserva, añadir enlaces contextuales al servicio correspondiente y a
   contacto; revisar título, descripción, encabezado principal y fecha de
   actualización.
5. Si se retira, elegir una redirección 301 equivalente o un 404/410 según la
   decisión del inventario. No redirigir automáticamente a inicio.

Los equipos, marcas, garantías, síntomas y procesos solo se redactan después de
confirmarlos con el negocio. Hasta completar esta revisión, no existen artículos
indexables en el sitemap nuevo.
