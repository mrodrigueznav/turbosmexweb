# 02: Navegación y crecimiento del catálogo

**What to build:** Una persona puede descubrir los turbos publicados desde una entrada de catálogo, categorías y enlaces relacionados, y el negocio puede ampliar el catálogo con productos seleccionados por demanda, historial comercial o inventario recurrente sin crear páginas duplicadas.

**Blocked by:** 01 — Colección Markdown y primer producto publicado

**Status:** ready-for-agent

- [ ] Existe una entrada pública de catálogo que enlaza únicamente a productos publicados.
- [ ] Las categorías de marca o aplicación contienen contenido propio y no se publican cuando están vacías o no tienen una intención útil.
- [ ] Los productos publicados son alcanzables mediante navegación, enlaces contextuales o categorías relevantes.
- [ ] Se incorporan los primeros productos adicionales usando el formato Markdown validado, con información comercial y técnica confirmada.
- [ ] Las páginas de producto incluyen breadcrumbs y enlaces relacionados hacia venta, reparación, refacciones o contacto cuando sean pertinentes.
- [ ] El sitemap contiene todas las páginas públicas canónicas del catálogo y ninguna ruta alternativa o producto retirado.
- [ ] Las pruebas detectan enlaces internos rotos, categorías vacías y productos publicados sin contenido mínimo.
