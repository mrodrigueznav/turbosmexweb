# 01: Colección Markdown y primer producto publicado

**What to build:** Un responsable editorial puede añadir un producto mediante un archivo Markdown validado, y una persona visitante puede consultar el primer turbo publicado en una página completa, con información técnica confirmada y una ruta clara para solicitar cotización.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Existe una colección de productos Markdown con campos obligatorios y validación para evitar productos incompletos o datos inválidos.
- [ ] Un primer turbo real se publica mediante una plantilla reutilizable con nombre, marca, número de parte, aplicaciones confirmadas, condición, disponibilidad comunicable e imagen cuando existan esos datos.
- [ ] La página distingue consulta y cotización de compra en línea, y no afirma precio, compatibilidad o inventario no confirmados.
- [ ] La página tiene título, descripción, H1, canonical, metadatos sociales, CTA de contacto y datos estructurados únicamente para información visible y confirmada.
- [ ] El producto publicado aparece en el sitemap y los productos no publicados no aparecen en páginas públicas ni en el sitemap.
- [ ] La construcción y la suite de publicación comprueban rutas, metadatos, accesibilidad básica y enlaces internos del primer producto.
