# 03: Señales técnicas e indexación

**What to build:** Señales técnicas consistentes para declarar URLs preferidas,
mejorar el uso compartido y verificar el rastreo del sitio nuevo.

**Blocked by:** 01: Inventario de URLs y redirecciones; 02: Contenido diferenciado de servicios y ubicaciones.

**Status:** ready-for-human

- [x] Cada página pública incluye una URL canonical correcta.
- [x] Cada página pública incluye metadatos Open Graph y Twitter coherentes.
- [x] Los datos estructurados de organización o negocio local usan únicamente información verificable.
- [x] El sitemap contiene las URLs públicas canónicas esperadas.
- [x] Se verifica que robots, sitemap y rutas públicas sean rastreables en el dominio definitivo.
- [x] Se revisan títulos y descripciones para búsquedas de compra sin crear páginas repetitivas.
