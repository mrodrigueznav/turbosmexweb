# 02: Contenido diferenciado de servicios y ubicaciones

**What to build:** Páginas de servicios y ubicaciones con información útil,
propia y confirmada por el negocio.

**Blocked by:** 01: Inventario de URLs y redirecciones.

**Status:** ready-for-human

- [x] Venta, reparación y refacciones explican procesos, datos útiles y alcance real.
- [x] Se incluyen equipos, marcas, síntomas, recepción desde otras ciudades o garantías solo cuando estén confirmados.
- [x] Las ubicaciones distinguen sucursales abiertas al público de cobertura por envío.
- [x] No se publica una sucursal sin dirección, teléfono, horario, mapa y servicios confirmados.
- [x] Se evalúa la URL de Guanajuato antes de retirarla o redirigirla.
- [x] Las páginas contienen llamadas a contacto y no hacen promesas no verificadas.
