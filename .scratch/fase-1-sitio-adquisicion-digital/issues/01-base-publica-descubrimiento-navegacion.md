# 01: Base pública de descubrimiento y navegación

**What to build:** Una experiencia pública coherente para que visitantes descubran los servicios de Turbos México, entiendan las aplicaciones atendidas y lleguen a una acción de contacto desde cualquier página.

**Blocked by:** None (can start immediately).

**Status:** ready-for-human

- [x] La página de inicio comunica venta, reparación y refacciones, aplicaciones atendidas y cobertura nacional.
- [x] Las páginas de venta, reparación, refacciones, ubicaciones y contacto son accesibles desde rutas claras.
- [x] Cada servicio ofrece una llamada a la acción hacia contacto o WhatsApp.
- [x] La navegación global funciona en móvil y escritorio, incluido el menú móvil con estado accesible.
- [x] Todas las páginas mantienen identidad visual, idioma español de México, título, descripción y encabezado principal coherentes.
- [x] Los enlaces telefónicos, de correo y WhatsApp tienen destinos válidos y etiquetas comprensibles.
- [x] Las páginas se generan correctamente como sitio estático.
