# 04: Accesibilidad, responsive y verificación de publicación

**What to build:** Una validación final del flujo público completo que confirme que el sitio se puede usar, construir y publicar de forma confiable en los contextos principales de la Fase 1.

**Blocked by:** 01: Base pública de descubrimiento y navegación; 02: Solicitud de contacto y persistencia segura de leads; 03: Medición de conversiones verificables.

**Status:** ready-for-human

- [x] La navegación y el menú móvil pueden operarse con teclado y tienen nombres y estados accesibles.
- [x] Los campos del formulario tienen etiquetas asociadas y los mensajes de estado se anuncian a tecnología asistiva.
- [x] Las acciones principales siguen visibles y utilizables en un viewport móvil y uno de escritorio.
- [x] El flujo página → contacto → envío o alternativa de WhatsApp funciona de extremo a extremo.
- [x] Las páginas tienen enlaces internos válidos, metadatos coherentes y una estructura semántica verificable.
- [x] La construcción del sitio termina sin errores y produce todas las páginas públicas esperadas.
- [x] Las pruebas de regresión cubren navegación, formulario, conversiones, accesibilidad básica y metadatos.
- [x] Se documentan como pendientes las decisiones operativas de privacidad, respaldo y retención de leads antes del lanzamiento definitivo.
